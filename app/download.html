Installing on Windows

Up and running in under a minute.

1

Download the file

Click Download for Windows above to get Credent-1.1.0-Setup.exe.

2

Run it

Double-click the downloaded file. It's a portable build — no admin install needed.

3

If SmartScreen appears

Because this is a fresh beta, Windows may show "Windows protected your PC." Click More info → Run anyway. Code signing is coming.

4

Meet Emrys

The app opens to the Emrys glow. Sign in and start your first lesson.
